# 后台权限与论坛管理

更新时间：2026-11-14  
适用版本：`2.9.x`

## 1. 权限原则

- 除「设置」外，后台每个板块都需要对应权限；
- 超级管理员始终拥有全部权限；
- 成员与权限模块只允许超级管理员访问；
- 超级管理员可以给任意成员分配任意权限；
- 高级管理员不能单独修改成员权限，也不能访问成员与权限模块；
- 前端按权限隐藏导航、面板和操作；后端独立校验，不能只靠隐藏。

## 2. 板块与权限

| 板块 | 权限 |
| --- | --- |
| 后台总览 | `admin.overview` |
| 主页资料 | `home.edit` |
| 文章 / 照片 / 视频 | `archive.articles` / `archive.photos` / `archive.videos` |
| 项目库 | `projects` |
| 日志内容 | `logs` |
| 留言板 | `guestbook` |
| 论坛创建与维护 | `forum.maintenance`、`forum` 或具体 `forum.<id>` |
| 论坛成员管理 | 对应类别总管理 `forum.category.<access>.master`；`forum` 为全部论坛 |
| 论坛公告 | `forum.announcements` 或 `forum` |
| 待审帖子 | `forum.review` 或 `forum` |
| 特殊/核心申请 | `forum.access` 或 `forum` |
| 审核日志 | `review.logs` |
| 举报处理 | `reports.manage` |
| 内容安全 | `moderation.manage` |
| 安全日志 | `security.logs` / `access_logs` / `security.readonly` |
| 主题颜色 | `themes.manage` |
| 设置 | 所有 staff，无需额外权限 |
| 成员与权限 | 仅 `isSuper`，没有可授予的普通权限 |

## 3. 权限树

权限树已改为可伸缩布局：

- 顶部搜索：支持权限名、论坛名、slug、论坛 ID；
- 论坛类别筛选：全部 / 普通 / 特殊 / 核心；
- 全局论坛权限：`forum`、创建、维护、成员、公告、审核、申请、帖子免审；
- 论坛列表默认紧凑显示，点「细分」展开单个论坛的 7 项操作；
- 「全选结果」和「清空结果」只影响当前搜索/分类结果；
- 已选数量与论坛数量实时显示；
- 100 个论坛时无需滚动完整长列表，可搜索或按类别批量操作。

## 4. 成员与权限

- 只有超管能打开；
- 权限编辑只有超管可见、可调用；
- 保留快捷身份模板：
  - 内置：内容审核员、论坛维护员、只读审计；
  - 超管可新增/编辑自定义模板；
  - 模板可搜索选择目标成员并一键应用；
- 旧「身份管理」面板已移除，不再作为独立导航。

## 5. 论坛成员管理

「论坛 → 论坛成员管理」：

0. 只有对应类别总管理能进入身份授予；子管理员只能授予本论坛免审；
1. 搜索并选择成员；
2. 选择论坛类别（全部 / 普通 / 特殊 / 核心）；
3. 选择管理员类型（总管理员 / 子管理员）；
4. 子管理员必须再选择具体论坛，可按论坛名搜索；
5. 总管理员授予当前类别下全部论坛；
6. 候选成员自动排除超管、高级管理员、论坛总管理员和拥有全部论坛权限的账号。

## 6. 论坛创建与维护

- 不再有「创建论坛」独立导航；
- 不再有普通/特殊/核心三个独立导航；
- 统一入口「论坛创建与维护」；
- 内部横向滑块按论坛切换，默认选中第一个有权限的论坛；
- 无权限论坛不会显示，不能通过滑块切换；
- 顶部图表：论坛数量、帖子总数、回复总数、待审内容、活跃用户；
- 选中论坛图表：帖子、回复、待审、活跃用户；
- 创建论坛卡片位于图表下方，类别固定为当前滑块论坛的类别；
- 板块公告、帖子、等级/头衔均移动到选中论坛卡片内。

## 7. 等级与头衔

- 删除全局「头衔等级」导航；
- 每个论坛独立维护等级、最低积分与头衔；
- 每个论坛可单独给成员发放/锁定头衔；
- 新产生的发帖/回复按论坛规则写入 `forum_member_titles`；
- 公开论坛帖子和回复优先读取该论坛的头衔，没有则回退全局头衔。

## 8. 审核日志

- 新增「论坛 → 审核平台 → 审核日志」；
- 复用安全审计日志的 SHA-256 不可篡改链；
- 支持操作者/路径/对象/IP、动作、日期筛选；
- 导出 CSV 时严格按照**已经应用**的筛选条件；
- 导出上限 5000 条，避免一次请求拖垮服务。

## 9. 公告删除

- 板块公告允许该板块管理员删除；
- 全局公告只允许全部论坛管理员或超管删除；
- 修复了此前板块管理员无法删除公告的问题。
