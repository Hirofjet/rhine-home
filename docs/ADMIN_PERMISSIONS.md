# 后台权限与论坛管理

更新时间：2026-11-14  
适用版本：`2.10.2`

## 1. 权限原则

- 除「设置」外，后台每个板块都需要对应权限；
- 超级管理员始终拥有全部权限；
- 成员与权限模块只允许超级管理员访问；
- 超级管理员可以给任意成员分配任意权限；
- 高级管理员不能单独修改成员权限，也不能访问成员与权限模块；
- 前端按权限隐藏导航、面板和操作；后端独立校验，不能只靠隐藏；
- 权限增删后，后端实时重算身份和全局头衔；没有匹配身份时回到普通成员；
- 免审、公告、待审等单项权限不会单独构成论坛管理员身份；
- 类别总管理授权在现有权限上合并，不覆盖其他类别或成员原有权限；
- 论坛维护固定显示普通/核心/特殊三个类别。

## 2. 身份与权限

| 身份 | 权限 |
| --- | --- |
| 超级管理员 | 全部权限，`isSuper` 绕过校验 |
| 高级管理员 | 后台总览、留言板、举报处理、内容安全、审核日志、安全日志、访问日志、主题颜色、项目库、日志内容、论坛全部权限 |
| 论坛总管理员 | 论坛全部权限 |
| 普通/核心/特殊论坛总管理员 | 对应类别全部论坛权限，包括创建论坛、公告、审核、免审、版务 |
| 普通/核心/特殊论坛管理员 | 对应论坛全部权限 |
| 监管只读 | 安全只读 |
| 普通成员 | 无后台身份；论坛显示全局头衔或子论坛头衔 |

## 3. 四总管理权限

权限树提供四个总管理权限和单项权限，均可勾选：

- `forum`：论坛总管理
- `forum.category.public.master`：普通论坛总管理
- `forum.category.core.master`：核心论坛总管理
- `forum.category.special.master`：特殊论坛总管理

勾选后自动包含对应全部论坛权限；取消后同步移除对应类别/论坛派生权限。

四项之外仍保留单项权限复选框：

- 类别创建论坛：`forum.category.<access>.create`
- 子论坛公告：`forum.<boardId>.announcements`
- 子论坛待审：`forum.<boardId>.review`
- 子论坛免审：`forum.<boardId>.post.autoapprove`
- 子论坛版务：`forum.<boardId>`

勾选四个总管理权限会自动勾选全部对应单项；取消时会同步取消。总管理未勾选时，单项可单独勾选。类别子管理员仍通过「论坛成员管理」授予。

旧权限 `forum.members`、`forum.announcements`、`forum.review`、`forum.access`、`forum.create`、`forum.maintenance` 不再作为权限树勾选项，保留后端兼容。

## 4. 权限树

- 四个总管理权限单独列出；
- 其余论坛权限按普通/核心/特殊三个类别版块展示，可单独勾选；
- 每个论坛提供版务、公告、待审、免审四个单项复选框；
- 论坛搜索支持论坛名、slug、ID；
- 非论坛权限保留独立复选框。

## 5. 身份与头衔

- 赋予身份时默认写入全局头衔；
- 权限增删后重新计算身份，并重新写入匹配的全局头衔；
- 没有匹配身份时回到普通成员，并清空全局头衔；
- 普通成员没有全局头衔，论坛回退读取子论坛头衔；
- 论坛展示顺序：先全局头衔，再子论坛头衔；
- 删除权限弹窗中的「身份组」卡片，身份由权限自动推导。

## 6. 论坛成员管理

- 只有对应类别总管理能授予/删除论坛成员身份；
- 子管理员只能授予本论坛帖子免审；
- 总管理员授予后拥有该类别全部论坛；
- 子管理员授予后拥有对应论坛全部权限；
- 候选成员排除高级管理员及以上；
- 成员列表以用户为主要单位；
- 一个用户卡片展示全部论坛身份；
- 支持一次移除该用户全部论坛身份。

## 7. 论坛创建与维护

- 统一入口「论坛创建与维护」；
- 内部为普通/核心/特殊三个类别滑块；
- 类别内显示统计卡、图表、论坛卡片；
- 创建论坛绑定当前类别，并需要该类别总管理权限；
- 板块公告、帖子、等级/头衔均在选中论坛卡片内维护。

## 8. 等级与头衔

- 每个论坛独立维护等级、最低积分与头衔；
- 每个论坛可单独给成员发放/锁定头衔；
- 新产生的发帖/回复按论坛规则写入 `forum_member_titles`；
- 公开帖子/回复优先读取全局头衔，没有全局头衔才读取子论坛头衔。

## 9. 审核日志

- 入口「论坛 → 审核平台 → 审核日志」；
- 复用安全审计日志的 SHA-256 不可篡改链；
- 支持操作者/路径/对象/IP、动作、日期筛选；
- 导出 CSV 严格按已应用筛选条件；
- 导出上限 5000 条。
