# 后台管理

入口：`/admin`。后台与前台共用左侧导航，内部使用后台子导航切换模块。

## 模块清单

| 分组 | 模块 | 用途 |
| --- | --- | --- |
| 总览 | 概览 | KPI、ECharts 图表、待审入口 |
| 主页 | 主页资料 | 站点品牌、个人资料、首页展示 |
| 档案 | 文章 / 照片 / 视频 | 内容发布、编辑、删除 |
| 项目 | 项目库 | 项目编号、状态、链接、详情 |
| 日志 | 日志 | Markdown 日志与实时同步 |
| 论坛 | 主页公告 / 创建论坛 / 普通 / 特殊 / 核心 | 板块与公告管理 |
| 审核 | 特殊申请 / 待审帖子 | 访问申请与内容审核 |
| 互动 | 留言板 | 留言搜索与删除 |
| 成员 | 成员与权限 / 身份管理 | 账号、角色、身份组、权限 |
| 设置 | 访问记录 / 主题颜色 / 设置 | 审计、主题、个人密码 |

## 内容发布

- 文章：标题、日期、标签、Markdown、附件；
- 照片：文件或 URL，日期来源可选「读取照片时间戳」或「手动设置发布时间」；
- 视频：文件或 URL、封面、描述；
- 日志：正文可直接写 Markdown，也可导入 `.md`；
- 项目：名称、编号、状态、版本、GitHub 与详情。

上传文件写入 `UPLOAD_DIR`，通过 `/uploads` 访问。大文件需要同时调整 Nginx `client_max_body_size`。

## 论坛治理

- 板块分为公开、特殊、核心；
- 普通用户帖子进入审核；具备板块权限的管理员可直接发布；
- 支持置顶、隐藏、删除、恢复、公告；
- 删除按角色进入审批流程；超级管理员可直接删除；
- 特殊板块申请在审核平台处理。

## 成员与权限

- 支持搜索、角色筛选、身份组；
- 可重置密码、封禁（限时/永久）、删除；
- 权限树支持父级与子级授权；
- 只有拥有 `members.grant` 的账号能授权，且不能修改自己的权限。

详细规则见 [权限体系](PERMISSIONS.md)。

## 主题颜色

后台可创建自定义页面主题：

- 主题名；
- 主色 / 副色 / 子色；
- 三种颜色的名称；
- 删除自定义主题。

主题只影响页面，不影响 3D 档案主题。

## 访问记录

记录登录与关键访问行为，可按范围清理。清空操作不可恢复。

## 个人设置

后台「设置」只修改当前账号密码：需要当前密码，新密码两次确认。超级管理员也只能通过这里修改自己的密码。
