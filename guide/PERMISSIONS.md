# 权限体系

## 角色

| 角色 | 说明 |
| --- | --- |
| `super` | 超级管理员，全部权限，不可删除 |
| `admin` | 管理员，按授予权限管理内容与成员 |
| `moderator` / 身份组 | 论坛版主或自定义身份组，按板块授权 |
| `user` | 普通注册用户 |

另有封禁状态：限时封禁与永久封禁。永久封禁会把邮箱加入黑名单并立即使会话失效。

## 权限树

```text
archive
├── archive.articles
├── archive.photos
└── archive.videos
projects
logs
forum
├── forum.<boardId>
└── forum (全部板块)
guestbook
members.manage
members.grant
access_logs
```

### 说明

- `archive` 是父级权限，包含三个子权限；
- `forum` 可整体授予，也可按板块 ID 授予；
- `members.manage` 管理成员，`members.grant` 修改他人权限；
- `access_logs` 查看/清理访问记录；
- 超级管理员隐式拥有全部权限。

## 身份组

身份组是一组权限集合，可绑定到成员，也可作为板块管理角色使用。身份组的权限仍然受“不可自我提权”和“管理账号互斥”规则约束。

## 边界规则

1. 只有 `members.grant` 可以授权他人。
2. 任何人不能修改自己的权限。
3. 拥有管理类权限的账号之间不能互相操作，只有超级管理员例外。
4. 普通管理员不能操作超级管理员。
5. 超级管理员不可删除。
6. 非本人不能修改超级管理员密码。
7. 被封禁账号不能登录，已登录会话立即失效。
8. 邮箱验证码注册；找回密码走邮箱验证码。
9. 访客只能访问公开板块与公开内容。

## 前端与后端的双重校验

前端隐藏无权限入口，后端对每个管理接口再次校验。不要依赖前端隐藏来实现安全。

## 新增权限时的检查清单

- 是否加入权限树与后台侧栏；
- 后端接口是否执行 `requireAuth` 与权限判断；
- 前端是否隐藏无权按钮；
- 是否影响身份组编辑器；
- 是否记录访问/管理日志；
- 是否补充测试与本文档。
