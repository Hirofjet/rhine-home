# Lab 与离线

## 模式

档案库和论坛支持：

- `?mode=lab`：3D 场景；
- `?mode=archive`：普通长页面。

模式记忆保存在 `rhine:view-mode`。档案库默认内容页为日志。

## 3D 结构

- 列：日志 / 文章 / 照片 / 视频 / 项目库；论坛模式为板块；
- 行：每列 8 个档案位；
- 右侧面板：模块、编号、标题、摘要、模块/日期/作者/状态；
- 页签：模块重点、研究记录（普通档案）或回复（论坛）、访问日志；
- 详情页保留文件编号、收藏、返回概览。

## 内容同步

- 页面打开时读取 `/api/content/*` 或 `/api/forum/*`；
- 档案库不再在内容变化后强制整页刷新；
- 同步失败时回退到内置档案，3D 场景继续启动；
- 照片等文本会截断到安全长度，避免异常标题阻塞渲染。

## 离线缓存

缓存名：`rhine-lab-3d-v2`。

- 首次加载自动保存当前已加载的 3D 核心资源；
- 手动「保存 3D 资源」/「清除本地资源」；
- 入口页网络优先，静态资源缓存优先；
- 缓存为空时自动重新下载；
- 启动失败时清空缓存并重试一次；
- 清除后 Service Worker 注销，下一次加载重新建立。

> 如部署了新版本但 3D 仍加载旧资源，请在浏览器 DevTools 清除站点数据，或使用设置中的清除资源。

## 性能

- 读取设备刷新率作为垂直同步目标；
- 不固定锁定 60fps；
- 根据 FPS 自适应调整内部渲染比例；
- 档案浏览阶段关闭景深，详情页启用；
- 可选 FPS HUD 显示 FPS / Hz / 分辨率 / 比例。

## 相关设置

- 页面主题：影响整个站点 UI；
- 3D 档案主题：只影响 3D 场景明暗；
- 3D 画质：完整 / 性能；
- 3D 开关：不提供，Lab 始终为 3D。
