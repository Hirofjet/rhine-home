# 内容系统

## 文章

字段：标题、日期、标签、Markdown、附件、可见状态。

- 正文使用 react-markdown + remark-gfm；
- 附件由上传接口保存，公开下载路由为 `/api/downloads/...`；
- 前台按日期倒序展示；
- 后台可编辑、删除、控制可见性。

## 照片

字段：URL、名称、日期、描述。

日期有两种来源：

1. **读取照片时间戳**：上传时读取 EXIF `DateTimeOriginal`，没有则读取 `CreateDate`；
2. **手动设置发布时间**：忽略 EXIF，使用填写的日期。

上传流程：

```text
选择文件 → 前端预览 + EXIF 尝试
→ 上传文件（服务端再次解析 EXIF）
→ POST /api/admin/photos
→ 前台时间线按日期排序
```

如果未读取到 EXIF，界面会提示并自动切换为手动日期。日期字段始终作为兜底。

## 视频

字段：URL、标题、描述、封面、标签。支持上传或外链。

## 日志

- 后台直接写 Markdown；
- 支持导入 `.md`；
- 前台日志页展示模块，可展开阅读；
- 日志也作为 3D 档案库的第一列。

## 项目库

字段：编号、名称、简介、标签、类型、状态、作者、版本号、GitHub、详情、创建/更新时间。

项目编号按顺序生成；后台支持弹窗编辑与预览。

## 留言板

- 公开留言，访客可发布；
- 访客令牌保存在本地，用于删除自己刚发布的留言；
- 后台可搜索、删除；
- 留言会以滚动/弹幕方式展示。

## 论坛

- 板块：公开 / 特殊 / 核心；
- 帖子：标题、标签、Markdown、附件、置顶；
- 回复：图片/GIF、楼中楼；
- 审核：普通用户帖子进入待审；有板块权限的管理员可直接发布；
- 删除：按角色进入审批，超级管理员可直接删除。

## 内容可见性

- 前台只返回已发布/已通过内容；
- 后台可查看待审与已隐藏内容；
- 访客只能看到公开内容；
- 私有资料、邮箱、封禁原因等只对授权角色可见。
