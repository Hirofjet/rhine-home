> 作者：Hirofjet

- 版本主题：类别授权合并、免审身份误判与滑块消失修复

## 根因

数据库中的 `permissions` 是 JSON 字段，驱动会直接返回数组；部分接口再次执行 `JSON.parse()` 会失败并把权限当成空数组，随后又覆盖写回。

这导致：

- 授予全部类别总管理时，后一次类别授权覆盖前一次，最后只剩一个类别；
- 重复分配已有子管理员时，只保留当前论坛权限；
- 免审授权后其他权限被覆盖；
- 角色和头衔根据被覆盖后的权限计算，出现“只给免审却变成管理员”；
- 论坛维护页只显示有权限的类别，看起来像滑块消失。

## 修复

- 增加统一的权限数组解析函数，兼容数组和字符串；
- 类别总管理授权改为在现有权限上合并，不再覆盖其他权限；
- 论坛总管理员一次选择“全部类别”时：
  - 普通、核心、特殊三个类别权限都会写入；
  - 即使该类别下暂时没有论坛，也保留类别总管理权限；
- 重复授予已有论坛成员：
  - 已是同角色时返回成功；
  - 子管理员可升级为总管理员；
  - 不再因为“已存在”而漏发类别权限；
- 免审授权改为数据库 JSON 原子增加/删除，不覆盖其他权限；
- 免审权限不会参与论坛管理员身份判定；
- 每次权限变更后重新计算身份和全局头衔；
- 成员列表加载时自动校正历史遗留的论坛角色；
- 论坛维护页始终显示普通/核心/特殊三个类别滑块。

## 测试结果

### 类别合并

对同一成员依次授予：

```text
普通论坛总管理
核心论坛总管理
特殊论坛总管理
```

最终权限：

```text
forum.category.public.master
forum.category.core.master
forum.category.special.master
forum.11
forum.12
forum.13
forum.24
guestbook
```

身份：

```text
论坛总管理员
```

原有 `guestbook` 保留。

### 重复分配

先用核心论坛子管理员身份测试，再分配核心论坛总管理员：

- 返回 200；
- 核心论坛权限保留；
- 类别总管理权限补齐；
- 不再跳过类别授权。

### 免审

普通成员只有：

```text
guestbook
```

授予 11 号论坛免审后：

```text
guestbook
forum.11.post.autoapprove
```

身份：

```text
普通成员
```

全局头衔为空，权限没有被覆盖。

### 滑块

论坛创建与维护现在固定显示：

```text
普通论坛 / 核心论坛 / 特殊论坛
```

不再因为只持有普通论坛权限而隐藏另外两个类别。
