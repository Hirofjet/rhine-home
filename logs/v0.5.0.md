# v0.5.0 更新日志

- 发布日期：2026-11-01
- 提交：`e2fbcc4`
- 版本主题：后台、鉴权与模块权限

## 版本概述

项目从静态主页进入可运营阶段：加入管理后台、登录鉴权、模块级权限、上传和动态内容 API，并进行性能与动效整理。

## 主要变更

- 管理后台与管理员登录；
- 账号鉴权与会话；
- 模块级权限控制；
- 图片、视频、文件上传；
- 动态内容 API；
- 文章附件下载；
- 性能与动画优化。

## 影响范围

- 新增后台与鉴权体系；
- 前台内容开始从数据库读取；
- 上传目录与数据库成为必需运行依赖。

## 验证

- 后台可登录并管理模块；
- 权限不足的账号看不到无权模块；
- 上传与内容 API 正常；
- 构建通过。
