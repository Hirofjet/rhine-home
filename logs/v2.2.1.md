# v2.2.1 更新日志

- 发布日期：2026-11-05
- 版本主题：EXIF 日期时区与文档补丁

## 版本概述

修复照片 EXIF 日期转换的时区偏移；补齐普通用户关注入口与照片日期选择；完成 README、guide 教程、需求演进和本地版本日志体系。

## 主要变更

- EXIF DateTimeOriginal 改为本地年月日，不再直接用 UTC ISO 日期。
- 照片发布支持读取拍摄时间或手动发布时间。
- 论坛帖子作者可点击进入 `/u/:id`，公开资料页可关注。
- 个人资料关注页增加发现成员说明。
- 左侧导航设置和下拉框宽度跟随导航栏。
- README 重写：Lab 致谢、开源承诺、系统架构、权限、ECharts、离线与版本演进。
- 教程统一迁移到 guide/。
- 新增 logs/ 版本日志，v0.5.0 之后每版一篇；自 v2.4.0 起纳入 Git。

## 验证

- EXIF 测试图片拍摄时间读取为 2024-05-06，日期来源为 exif。
- 论坛作者资料链接可进入公开用户页。
- 后台照片日期来源与日期输入存在。
- 窄导航下设置下拉不溢出。
- `npm run build` 与 `npm run lint` 通过。
