# Hirofjet//Home-v2.7.0 更新日志

> 作者：Hirofjet

- 发布日期：2026-11-11
- 版本主题：项目库修复、隐私与安全加固

## 版本概述

修复项目库偶发空白，调整内容审核策略，补齐隐私政策、数据导出/注销、安全响应头、验证码与会话加固，并加入备份与安全运营手册。

## 主要变更

### 项目库

- 空项目数组不再写入 5 分钟缓存，避免一次空响应造成持续空白；
- 项目接口空结果自动重试一次；
- 首屏优先读取最近一次成功缓存，减少空白时间。

### 内容审核（编号 5）

- 普通帖子、回复、留言直接发布；
- 只有命中「转人工审核」敏感词时进入待审；
- 命中「直接拒绝」敏感词仍立即拦截；
- 紧急停止仍可关闭全部发布。

### 隐私与数据（编号 8、9）

- 新增 `/privacy` 与 `/terms`；
- 注册必须同意协议，数据库记录协议版本和同意时间；
- 新增账号数据 JSON 导出；
- 新增账号注销：删除私信/留言/通知/会话/关注/屏蔽，匿名化公开资料；
- 新增退出其他设备；
- 隐私页说明保存期限、公开范围、未成年人、安全措施与联系方式。

### 安全响应头（编号 10）

- `X-Content-Type-Options`、`X-Frame-Options`、`Referrer-Policy`、`Permissions-Policy`；
- `Content-Security-Policy`；
- HTTPS 生产环境 HSTS；
- 关闭 `X-Powered-By`。

### 会话与验证码（编号 11）

- 验证码改用 `crypto.randomInt`；
- 单验证码最多 5 次尝试，超限作废；
- 注册、重置、验证码发送、全局 API 加了限流；
- 密码重置不返回邮箱是否存在；
- 支持退出其他设备。

### 备份、监控与运营（编号 12、13）

- 新增 `scripts/backup.mjs`（mysqldump + uploads tar + manifest SHA-256）；
- 新增 `scripts/security-check.mjs`（HTTPS、响应头、健康检查）；
- 新增 `docs/SECURITY_OPERATIONS.md`：WAF/限流、备份恢复、监控告警、隐私请求、年度评估、等保/渗透、发布检查和证据清单；
- 年度评估、渗透测试、等保测评属于组织执行项，需要按手册实际执行并归档，不能仅靠代码完成。
