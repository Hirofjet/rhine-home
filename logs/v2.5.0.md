# Hirofjet//Home-v2.5.0 更新日志

> 作者：Hirofjet

- 发布日期：2026-11-08
- 版本主题：数据一致性、权限与论坛成长

## 版本概述

修复后台删除/隐藏状态、权限与身份同步、项目同步和内容重复加载；补充论坛头衔与活跃等级、已读通知删除；扩大 3D Lab 内容容量并整理新增模块。

## 主要变更

### 论坛内容

- 后台帖子列表排除已删除记录；
- 已删除帖子不能通过隐藏/恢复重新出现；
- 删除操作清理置顶状态；
- 后台板块帖子数排除已删除内容。

### 权限与身份

- 身份不再自动把整类论坛加入权限；
- 身份变更保留已有板块权限；
- 保存权限时若已无法支撑身份头衔，自动降为普通成员；
- 权限树不再在勾选单一板块时自动添加全部板块；
- 权限树文案明确「全部板块」与逐项授权的区别。

### 论坛头衔

- 新增 `forum_title`、`forum_title_locked`、`forum_points`、`forum_level`；
- 新增 `forum_title_rules` 等级规则；
- 主题通过 +5、回复 +1；
- 达到积分自动发放头衔；
- 论坛管理员可手动发放并锁定头衔；
- 帖子、回复、公开资料和 3D 论坛显示头衔/等级。

### 消息

- 已读通知支持逐条删除；
- 支持清除全部已读通知。

### 3D Lab

- 每列最多 20 个档案（原 8 个）；
- 最多 12 个论坛板块（原 9 个池位、实际同步 8 个）；
- 文件号改为三位序号；
- 文件刻度在列切换/数量变化时重建。

### 内容与结构

- 新增 5 分钟本地内容缓存；
- 后台内容变更清空缓存并通知前台；
- 项目保存后主动刷新主页/项目库；
- 新增 `contentCache`、`AuthorTitle`、`ForumTitlesPanel` 模块。

## 验证

- 前端 `npm run build` 通过；
- `npm run lint` 0 错误；
- Lab 12 列导航和 12 条档案刻度通过浏览器验证；
- 后端 `node --check` 通过；
- 本地 MySQL 服务未运行，删除/权限/头衔 API 未做真实数据库回归，部署前需在服务器执行数据库迁移并验证。

## 备注

本地数据库未启动，因此本轮后端行为以静态检查、代码审查和前端构建为主；数据库迁移会在服务器启动时自动补齐字段与 `forum_title_rules` 表。
