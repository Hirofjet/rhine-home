# v2.3.1 更新日志

- 发布日期：2026-11-05
- 版本主题：论坛作者主页与快捷关注

## 版本概述

3D 与普通论坛统一作者社交入口：帖子作者、回复作者可进入公开个人主页；帖子页可直接关注作者。3D 内部通过 postMessage 交给外层 React 路由，避免在 iframe 中打开整页应用。

## 主要变更

- 3D 论坛内容页显示作者资料入口；
- 回复作者也可进入 `/u/:id`；
- 3D 论坛内容页新增关注作者按钮；
- 关注状态异步读取，作者本人隐藏关注按钮；
- 普通论坛帖子页新增关注作者按钮；
- 普通论坛回复作者改为资料链接；
- iframe 导航消息监听加入 ForumLabPage 与 LabArchiveView；
- 3D 静态资源重新构建。

## 验证

- 3D 作者按钮点击后父页面进入 `/u/1`；
- 作者本人关注按钮隐藏；
- 普通论坛作者链接和关注按钮存在；
- 构建通过。

## 备注

关注仍调用原 `/api/users/:id/follow` 接口，权限和登录态与公开主页一致。
