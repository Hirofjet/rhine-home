# Hirofjet//Home-v2.3.2 更新日志

> 作者：Hirofjet

- 发布日期：2026-11-05
- 版本主题：3D Markdown 渲染与阅读区自适应

## 版本概述

修复 3D 档案内容页把 Markdown 当纯文本显示的问题；同时扩大详情阅读区，解决特定比例与尺寸下正文显示过少、保存按钮被页脚遮挡的问题。

## 主要变更

- 引入 marked 与 DOMPurify；
- 文章、日志、项目详情与论坛正文统一渲染 Markdown；
- 支持标题、段落、粗体、斜体、链接、列表、引用、行内代码、代码块、表格；
- 档案阅读区高度提升到 340px；
- 移除过早触发的短屏高度压缩规则；
- 短视口保留滚动与保存操作；
- 3D 静态资源重新构建。

## 验证

- 3D 文章内容页 h1、ul、blockquote 均渲染为 HTML；
- 页面不再出现原始 `# 标题` 文本；
- 1600×900 阅读区高度约 263px，保存按钮位于页脚上方；
- 构建通过。

## 备注

Markdown 输出经过 DOMPurify 清理，避免正文中的原始 HTML/脚本注入。
