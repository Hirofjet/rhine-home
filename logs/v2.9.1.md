# Hirofjet//Home-v2.9.1 更新日志

> 作者：Hirofjet

- 发布日期：2026-11-14
- 版本主题：登录保持与 MFA 易用性

## 登录状态

- 原 12 小时会话改为 **30 天滑动会话**；
- 每次访问 API 时自动续期；
- 只有连续 30 天未访问才退出；
- 浏览器本地令牌长期保留，刷新/关闭浏览器后仍保持登录；
- 新增 `sessions.last_seen_at`；
- 升级时旧的有效会话自动延长到 30 天；
- 新增环境变量：

```env
SESSION_DAYS=30
```

## MFA

- MFA 绑定页新增二维码，可直接用认证器扫描；
- 保留手动密钥作为备用；
- MFA 不再只属于管理员，所有用户可用；
- 普通用户入口：个人资料 → 账号 → 动态验证码 / MFA；
- 默认关闭，用户自行开启；
- 关闭 MFA 需要当前密码和当前动态验证码；
- 设置页与个人资料页都支持二维码；
- 隐私政策同步更新。

## 验证

- 管理员登录会话有效期 30 天；
- `last_seen_at` 超过 5 分钟后访问会自动续期到 30 天；
- 普通用户默认 MFA 关闭；
- 普通用户可完成 setup → enable → 退出 → 无验证码登录 401 → 带验证码登录 200 → disable；
- 二维码 URI 为标准 `otpauth://totp/`；
- 构建通过，lint 0 错误。

## 备注

- MFA 二维码由前端 `qrcode` 库生成，不依赖第三方二维码接口；
- 关闭浏览器不会立即退出；退出需主动点击退出或连续 30 天不访问；
- 管理员可在需要时通过成员管理禁用账号或清理会话。
