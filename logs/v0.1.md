## 版本概述

RHINE//HOME 的第一个可运行版本。站点从零建立主页、档案库、项目库与实验室入口，确定 React + TypeScript + Vite + Tailwind CSS 的技术路线。

## 主要变更

- 建立首页、档案库、项目库与实验室四个基础页面；
- 使用 React 19 + TypeScript 搭建页面结构；
- 使用 Vite 8 构建；
- 使用 Tailwind CSS v4 建立第一批主题色工具类；
- 修正主题色前缀，确保 `rhine-*` 工具类可以被生成；
- 建立最初的站点视觉与个人信息展示。

## 开发记录

- 开发与调试使用 DeepSeek Harness；
- 记录中的模型为 DeepSeek-v4.1-flash；
- 这一版的重点是“先让网站跑起来”，尚未加入后台、论坛与 3D。

## 验证

- 基础路由可切换；
- 构建通过。
