- 版本主题：3D 档案库/论坛主题与导航双向同步

## 版本概述

把 3D 档案库、3D 论坛与导航设置的主题状态统一为双向同步，覆盖页面主题和 3D 档案明暗两套设置；同时冻结档案库 iframe 地址，避免切换主题导致 3D 重载。

## 主要变更

- 新增 labTheme 映射工具；
- 导航页面主题变化通过消息同步到两个 3D 库；
- 导航 3D 主题变化同步到两个 3D 库场景与内部下拉；
- 3D 内部页面主题变化通过 `rhine:page-theme` 更新导航和全局主题；
- 3D 内部 3D 主题变化通过 `rhine:lab3d-theme` 更新导航与本地存储；
- 父页面监听 3D 消息并更新 React ThemeProvider；
- 侧栏监听 3D 主题事件并更新下拉；
- 档案库 iframe 的 `src` 只初始化一次，主题切换不再重载。

## 验证

- 导航选择 archive + dark：档案库 3D 内部显示 archive + dark；
- 3D 内部选择 sakura + light：导航显示 sakura + light；
- 论坛导航选择 noctis + light：论坛 3D 内部同步；
- 论坛内部选择 archive + dark：导航同步；
- 构建通过。

## 备注

自定义 React 主题在 3D 内暂映射为亮色；内置页面主题与 3D 明暗完整同步。
