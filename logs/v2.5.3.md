## 版本概述

重做普通档案模式的照片时间线：时间轴居中、图片左右交错、图片优先放大并适配横竖屏。同步修正 3D 文件号显示与翻页后的卡片/刻度位置。

## 主要变更

- 照片时间线居中，年份节点居中；
- 图片卡片按顺序左右交错；
- 图片卡片改为大图优先，竖图最高 32rem、横图最高 26rem；
- 浏览器加载后读取自然宽高，自动标记 PORTRAIT / LANDSCAPE；
- 移动端保持左侧时间轴、单列大图；
- 3D 文件号显示 `02-009` 形式，而不是 `X--009`；
- 翻页后文件号、刻度、卡片都从页首开始；
- 档案库与论坛共用分页、文件号、内容同步逻辑。

## 验证

- 4 张照片：左右左右交错，时间轴居中；
- 竖图/横图分别按对应最大高度展示；
- 24 条 Lab 内容：3 页，每页 8 条；
- 第 2 页从第 9 条、第 3 页从第 17 条开始；
- 翻页后页面卡片回到顶部位置；
- `npm run build` 通过，`npm run lint` 0 错误。

## 备注

照片页面的 PORTRAIT / LANDSCAPE 标签由图片加载后的自然尺寸决定；未加载完成前先按横图占位。
