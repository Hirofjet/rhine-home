# Hirofjet//Home-v2.7.1 更新日志

> 作者：Hirofjet

- 发布日期：2026-11-11
- 版本主题：个人资料逐项可见范围

## 主要变更

- 性别、生日、个人简介、标签分别新增可见范围；
- 三档范围：
  - `public`：所有人可见
  - `friends`：互相关注好友可见
  - `private`：仅自己可见
- 服务端根据访问者身份、互相关注关系过滤字段；
- 非本人不会拿到被隐藏字段的值，而不是只在前端隐藏；
- 个人资料页在性别、生日、简介、标签旁提供可见范围选择器；
- 公开用户页按范围显示性别、生日、简介和标签；
- 隐私政策同步说明。

## 默认值

- 性别：仅自己；
- 生日：仅自己；
- 简介：所有人；
- 标签：所有人。

默认值保持与升级前行为一致，避免突然公开敏感字段。

## 验证

- 匿名访问：仅看到公开字段；
- 互相关注好友：看到好友字段；
- 仅自己字段：其他登录用户也看不到；
- 本人：看到全部字段；
- 构建通过，lint 0 错误。
