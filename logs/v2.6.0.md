# Hirofjet//Home-v2.6.0 更新日志

> 作者：Hirofjet

- 发布日期：2026-11-11
- 版本主题：举报投诉、内容审核、监管只读与 MFA

## 版本概述

完成安全整改清单编号 2、3、4、6、7：建立站内举报投诉闭环、私信与全内容审核、监管只读账号和 TOTP MFA，并补齐公开合规信息配置。

## 主要变更

### 举报与投诉

- 新增 `content_reports` 工单表；
- `/complaints` 支持匿名/登录提交、工单查询、申诉；
- 帖子、回复、私信、用户资料、留言支持举报；
- 后台「安全 → 举报处理」支持状态流转、处理说明、申诉查看和隐藏被举报内容；
- 举报处理结果通过站内通知返回。

### 内容审核

- 留言板增加 `pending/approved/rejected` 状态，默认先审后发；
- 普通用户论坛回复默认先审后发；
- 新增敏感词规则：转人工审核或直接拒绝；
- 新增紧急停止开关，覆盖帖子、回复、留言、私信；
- 后台「安全 → 内容安全」管理规则与开关；
- 管理员审核留言/回复后通知作者和帖子作者。

### 私信

- 新增 `user_blocks`，支持屏蔽/解除屏蔽；
- 被屏蔽双方无法查看或发送私信；
- 私信敏感词直接拦截并写审计；
- 私信消息支持举报，举报快照保存上下文。

### 监管与 MFA

- 新增 `regulator` 身份与 `security.readonly` 权限；
- 监管账号只能读安全日志和举报，服务端拒绝所有写操作；
- `/regulator` 独立只读视图；
- 新增 TOTP MFA：设置页绑定、登录时校验、支持关闭；
- 监管访问仍写入请求日志和审计。

### 公开合规

- 新增安全负责人、投诉邮箱/电话、ICP/公安备案号、接入商和备案日期环境变量；
- `/legal` 和 `/complaints` 展示公开联系信息；
- 未配置时保持占位，不伪造备案号。

## 验证

- 举报提交/查询/后台处理通过；
- 留言和回复待审、后台通过通过；
- 敏感词拦截通过（422）；
- 紧急停止返回 423；
- 屏蔽私信通过（403）；
- 监管账号读取日志/举报 200，写操作 403；
- TOTP：绑定、无验证码 401、带验证码 200、关闭通过；
- 构建通过，lint 0 错误。

## 备注

- MFA 目前为可选启用，尚未强制所有管理员绑定；建议上线后立即绑定。
- 真实 ICP/公安备案号需由站点运营者填写，代码不生成假备案号。
- 上传文件安全（清单编号 5）未在本版本范围内。
