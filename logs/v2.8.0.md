# Hirofjet//Home-v2.8.0 更新日志

> 作者：Hirofjet

- 发布日期：2026-11-11
- 版本主题：管理员专用 App 与推送通知

## 版本概述

新增仅管理员可登录的 PWA 管理 App，可安装到桌面/手机主屏，链接正式服务器；顶栏消息中心与 Web Push 会显示通知标题、正文和时间。

## 主要变更

### 管理员 App

- 独立入口 `/app/`，不出现 `SiteSidebar` 前台布局；
- 无注册入口，没有注册链接；
- 登录服务端 `appOnly: true`，创建 session 前检查 staff 权限；
- 非 staff 返回 `app_staff_only`，无法读取管理数据；
- 支持 MFA 动态验证码；
- 顶栏显示账号、角色、安装、开启通知、消息中心、退出；
- `v2.8.0` 默认进入管理总览，所有已有后台面板照常可用。

### PWA

- `app-manifest.webmanifest`：独立窗口、主题色、图标、启动路径；
- `app-sw.js`：安装缓存、导航离线回退、push、notificationclick；
- 支持正式站点 `/app/` 与 GitHub Pages 子路径；
- 安装后运行在独立窗口。

### 通知

- 新增 `push_subscriptions` 表；
- VAPID 公钥/私钥/主题配置；
- 订阅、退订、测试推送接口；
- `notify()` 同时发送站内通知与系统推送；
- `notifyStaff()` 面向所有 staff；
- 新举报、待审帖子、待审回复、待审留言自动通知；
- Service Worker 显示标题与正文，点击聚焦/打开 App。

### GitHub 发布

- `.github/workflows/pages.yml`：构建并部署 GitHub Pages；
- `.github/workflows/release-app.yml`：标签触发 Release，附带 `rhine-admin-app.zip`；
- Pages 地址：`https://hirofjet.github.io/rhine-home/app/`；
- 正式站点：`https://www.hirofjet.cn/app/`；
- 服务端默认 CORS 允许 `https://hirofjet.github.io`。

## 验证

- 管理员 appOnly 登录 200，普通账号 403 `app_staff_only`；
- App 登录页无注册入口，普通账号无法进入管理面板；
- Service Worker scope `/app/`，manifest 指向 app manifest；
- 浏览器订阅成功，测试推送接口返回 `sent: 1`；
- 正常发帖 pending 后，管理员收到「新帖子待审核」通知，正文含作者与标题；
- 构建通过，lint 0 错误。

## 备注

- PWA 安装依赖 HTTPS；本地 localhost 例外；
- 正式环境必须配置 VAPID 密钥，否则通知按钮提示未配置；
- iOS 需要 16.4+ 并先添加到主屏幕；
- GitHub Pages 需要在仓库 Settings → Pages 选择 GitHub Actions；
- 若要真正的 APK/IPA，需另行接入 Capacitor/Bubblewrap 和签名。
